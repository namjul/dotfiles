# Engineering skills

Load the skill that matches the task. There is no default pipeline.

| Aim | Skill |
| --- | --- |
| Agreed change into working code | `code` |
| Written implementation plan | `plan` |
| Design decision tree | `explore-design-space` |
| Root cause of a defect | `investigate` |
| Commit, or a commit message | `commit` |
| Commit only when open questions are not urgent | `commit-if-clear` |
| Review the branch diff | `sr-eng-review` |
| GitLab issues, merge requests, CI | `gitlab` |
| Names while discussing code | `vocabulary` |
| Smallest next code change | `minimal-step-pair-programming` |
| Simplest solution that works | `ponytail` |
| Walk a codebase module by module | `codebase-walkthrough` |
| Neovim RPC annotations | `neovim` |
| Learner writes the core | `socratic-code-mentor` |
| Steps only a human can perform | `wizard` |
| Executable zx markdown | `zx-markdown-scaffold` |
| OpenSpec tutoring | `openspec-generate-tutorial` |
| Compress a video | `video-compress` |
